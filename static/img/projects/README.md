# Project Images

This directory contains placeholder images for projects displayed in the portfolio.

## Required Images

- `v-server-setup.jpg` - V-Server Setup project image (recommended: 800x450px, 16:9 aspect ratio)
- `ai-chatbot-starter.jpg` - AI Chatbot Starter project image (recommended: 800x450px, 16:9 aspect ratio)
- `conduit-container.jpg` - Conduit Container project image (recommended: 800x450px, 16:9 aspect ratio)
- `docusaurus-portfolio.jpg` - Docusaurus Portfolio project image (recommended: 800x450px, 16:9 aspect ratio)

## Image Guidelines

- Format: JPG or PNG
- Recommended size: 800x450px (16:9 aspect ratio)
- Max file size: 200KB per image (optimize for web)
- Fallback: If images are missing, the Docusaurus logo will be used automatically

## Adding Images

1. Add your project images to this directory
2. Use descriptive filenames matching the project names
3. Optimize images for web (use tools like ImageOptim, TinyPNG, etc.)
4. Ensure images are relevant to the project and professional
